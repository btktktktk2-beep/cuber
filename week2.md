# Неделя 2. Файлы, права, поиск

Практика: своя виртуалка Xubuntu и OverTheWire Bandit (пройдены уровни 0–8).

## Навигация и файлы
| Команда | Что делает |
| --- | --- |
| `pwd` | показать текущую папку |
| `cd папка`, `cd ..`, `cd ~` | перейти в папку / на уровень выше / домой |
| `ls -a` | показать файлы, включая скрытые (имя начинается с точки) |
| `ls -l` | подробно: права, владелец, размер, дата |
| `touch`, `mkdir` | создать файл / папку |
| `cp`, `mv`, `rm` | копировать / переместить или переименовать / удалить навсегда |
| `cat`, `head -n 5`, `tail -n 3`, `less` | читать файл целиком / начало / конец / постранично |
| `./файл` | запустить файл из текущей папки (нужно право `x`) |

Странные имена файлов:
- имя начинается с минуса: `cat ./-`
- пробелы в имени: `cat "имя с пробелами"` или `cat имя\ с\ пробелами`
- проще всего: начать имя и нажать **Tab**

## Права доступа
`-rw-rw-r--` → тип файла, затем права владельца, группы и остальных.

r = 4, w = 2, x = 1. Примеры:
- `chmod 600 файл` → `rw-------` (пароли и ключи)
- `chmod 640 файл` → `rw-r-----`
- `chmod u+x файл` → право запуска только владельцу

Проверено на практике: файл с паролем при правах 644 читал другой пользователь, после `chmod 600` — `Permission denied`.

## Пользователи
| Команда | Что делает |
| --- | --- |
| `sudo adduser имя` | создать пользователя |
| `sudo passwd имя` | задать пароль |
| `su - имя` | войти под другим пользователем |
| `exit` | выйти |

`/etc/passwd` — список пользователей: `имя:x:UID:GID:описание:домашняя_папка:оболочка`. Хеши паролей лежат в `/etc/shadow`.

## Поиск
| Команда | Что делает |
| --- | --- |
| `file ./*` | определить тип всех файлов в папке |
| `find . -type f -size 1033c ! -executable` | найти файл по типу, размеру и правам |
| `find / -user bandit7 -group bandit6 -size 33c 2>/dev/null` | поиск по всей системе без ошибок доступа |
| `grep слово файл` | найти строки с этим словом |

`2>/dev/null` прячет ошибки. Если результат пустой — запусти без этой части: можно спрятать настоящую ошибку.

## SSH
`ssh bandit0@bandit.labs.overthewire.org -p 2220` — подключение к удалённому серверу по порту 2220.

## Выводы недели
- Linux различает регистр: `-l` ≠ `-L`, буква `l` ≠ цифра `1`.
- `>` перезаписывает файл, `>>` дописывает.
- Сначала `ls` — точное имя, потом действие.
- Читать текст ошибок: в нём почти всегда есть причина.
- Файлы с паролями — только `chmod 600`, пароли на скриншотах закрашивать.
