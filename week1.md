# Неделя 1. Лаборатория и первые команды

## Лаборатория
- VirtualBox + Xubuntu, 2 ГБ ОЗУ, 2 ядра, диск 25 ГБ. Включена виртуализация AMD SVM в BIOS.
- Образ скачан с официального зеркала, целостность проверена по SHA256 (`certutil -hashfile файл SHA256`).
- Сделан снимок чистой системы — можно откатиться за минуту.
- Сеть NAT: виртуалка выходит в интернет, но снаружи её не видно.

## Команды
| Команда | Что делает |
| --- | --- |
| `pwd` | показать текущую папку (полный путь) |
| `cd папка` | перейти в папку |
| `ls` / `ls -l` | список файлов / подробно |
| `mkdir папка` | создать папку |
| `echo "текст" > файл` | записать текст в файл (перезаписывает) |
| `echo "текст" >> файл` | дописать в конец файла |
| `cat файл` | показать содержимое |
| `команда1 \| команда2` | передать вывод одной команды другой |
| `wc -l` | посчитать строки |
| `ping -c 3 ya.ru` | проверить связь |
| `sudo apt update` / `sudo apt upgrade -y` | обновить список пакетов / поставить обновления |
| `passwd` | сменить свой пароль |
| `sudo timedatectl set-timezone Europe/Moscow` | установить часовой пояс |

## Пути
- `/` — корень системы.
- `/home` — абсолютный путь (от корня), `home` — относительный (от текущей папки).
- `.` — текущая папка, `..` — на уровень выше, `~` — домашняя папка.

## Выводы недели
- Linux различает регистр и символы: `-l` ≠ `-L` ≠ `-1`.
- Пароль при вводе не отображается — так задумано.
- Ошибку `LANF` вместо `LANG` система приняла молча: результат нужно проверять самому.
- Часовой пояс важен: неверное время ломает хронологию событий в расследовании.
- Пароли по умолчанию (`changeme`) меняются первым делом.
